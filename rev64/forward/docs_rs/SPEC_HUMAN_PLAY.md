# 军棋人机对战 · 业务规格说明书（Rust 正向开发基准）

> 本规格是 Rust 版 `junqi_rs` 的**功能对齐基准**。只描述"输入 → 输出"业务行为，
> 不引用任何逆向地址/汇编证据。每条规则可被一组测试用例锚定（见 §追溯矩阵）。
> 范围 = 人机对战（含两人热座/暗棋翻棋/明棋布局/悔棋/复盘/存档）。
> **砍掉**：蓝牙联机、四国军棋、联网对战、账号系统。

## 0. 数据模型与编码契约（可序列化/可测试基准，对齐 C junqi.h）

| 字段 | 类型 | 取值域 | 语义 |
|---|---|---|---|
| `cell.rank` | u8 | 0-24 | 0=空；1-9 普通（1 最强…9 最弱）；10 炸弹；11 地雷；12 军旗；**明棋红方存 rank+0xc（13-24）** |
| `cell.side` | u8 | {0,1,0xFF} | 0=蓝 1=红 0xFF=未定色（暗棋未翻） |
| `cell.revealed` | u8 | {0,1} | 0=背面（暗棋未翻）1=正面 |
| `cell.flags` | u8 | 0 | 冗余位（可由 rank 派生，规则引擎不读） |
| `turn` | u8 | {0,1} | 当前行棋方（蓝 0/红 1） |
| `stage` | enum | {PLAY, OVER} | 阶段（SETUP 死枚举省略） |
| `winner` | enum | {NONE(-1), BLUE(0), RED(1), DRAW(2)} | 胜负 |
| `mode` | u8 | {0,1} | 0=明棋 LAY 1=暗棋 FLIP |
| `moves_since_eat` | i32 | ≥0 | 连续无吃子步数（和棋 70 阈值） |
| `total_moves` | i32 | ≥0 | 总步数（和棋 1000 阈值） |
| `mines_cleared[2]` | i32 | ≥0 | 暗棋工兵挖雷计数 [蓝,红] |
| `pieces_left[2]` | i32 | ≥0 | 各方可动子数缓存（**增量扣减已废弃，由 refresh_movable_counts 全量重算**，对齐 C R7-A；Rust 当前不增量维护属对齐行为） |

**rank 编码还原**（`rank_of(cell)`）：
- `rank ≤ 12`：原值
- `rank > 12 且 side==RED`：`rank - 0xc`（明棋红方编码还原）
- `rank > 12 且 side∈{BLUE,0xFF}`：脏值哨兵 → 钳 12（军旗）

**格索引**：`idx = row*5 + col`（row 0-11，col 0-4）；`row = idx/5`, `col = idx%5`。

**30 字节布局 → 60 格映射**：蓝方 15 字节镜像到蓝半区（row0-5），红方 15 字节镜像到红半区（row6-11）；明棋红方 rank+0xc 编码，暗棋统一 raw 值 + side=0xFF。

| 项 | 值 | 说明 |
|---|---|---|
| 棋盘 | 12 行 × 5 列 = 60 格 | 索引 `row*5+col`；row0=蓝底线，row11=红底线 |
| 阵营 | 蓝 row0-5，红 row6-11 | 各 30 格 |
| 铁路 | 纵：仅 col2 贯穿（row0..11，行营/大本营除外）<br>横：row0/5/6/11 整行 | 非工兵直线滑行；工兵可拐弯 |
| 行营 | 全盘 10 格（每方 5）：蓝 (2,1)(2,3)(3,2)(4,1)(4,3)，红 (7,1)(7,3)(8,2)(9,1)(9,3) | 安全岛：敌方不能**吃**行营中子；空行营可一步进入；行营非铁路不可被滑行穿行（C board.c is_camp 10 格） |
| 大本营 | 蓝 (0,1)/(0,3)，红 (11,1)/(11,3) | 军旗落点；进后不可再动（受 cfg1 开关）；空大本营不可入 |
| 每方棋子 | 25 子（5 空位，镜像分布） | rank 编码：1-9 普通（1 最强…9 最弱），10 炸弹，11 地雷，12 军旗 |

### 1.1 棋子等级（rank，小数字 = 强）
```
1 司令 > 2 军长 > 3 师长 > 4 旅长 > 5 团长 > 6 营长 > 7 连长 > 8 排长 > 9 工兵
10 炸弹（碰任何子双方消失，含军旗）
11 地雷（不可动，仅工兵可挖；地雷 > 除工兵外所有子）
12 军旗（不可动，被扛判负）
```

## 2. 规则开关（cfg，游戏设置弹窗可配）

| 开关 | 语义 | 默认 |
|---|---|---|
| cfg0 和棋 | 70 步无吃子 / 总 1000 步 判和棋 | 开 |
| cfg1 大本营 | 进入大本营的棋子是否冻结不可再动 | 开 |
| cfg2 吃雷 | 工兵撞雷：开=成功挖雷（雷消失工兵存活），关=送死 | 开 |
| cfg3 吃旗 | 普通扛旗是否判胜：开=扛旗即胜，关=扛旗入位不终局 | 开 |
| cfg4 暗棋门槛 | 暗棋下雷/旗仅工兵可攻击（雷无门槛，旗需已挖满 3 雷） | 开 |

规则引擎读开关为**实时全局值**（非开局快照），改开关即时影响后续判定：
- **cfg1 大本营**：按**源格当前位置**实时判冻结（子进大本营后 cfg1 关→该子可再动；关→开→立即冻结），无历史"曾进入"锁定
- **cfg4 作用域**（暗棋 mode=FLIP 时）：① 雷仅工兵可攻 ② 旗仅工兵且已挖满 3 雷可扛 ③ 大本营普通子安全岛（敌方不可吃）——cfg4=0 时三条全退明棋语义
- **cfg3 关的不可逆影响**：扛旗入位后旗被移除，无法再触发扛旗胜（见 §4.1 cfg3 关终局闭包）；再开 cfg3 不恢复已占旗位

## 3. 走子合法性（`can_move(from, to) -> bool`）

前置拒收（任一命中即 false）：
- 阶段非 PLAY
- from == to；from/to 越界
- 源格为空
- 回合不符：`src.side != turn`（暗棋 0xFF 未定子翻棋定色前不可走）
- 源为军旗/地雷（不可动）
- cfg1 开 且 源格在大本营 → 不可动
- 源未翻明（暗棋 `!revealed` 或 `side==0xFF`）

目标约束：
- 目标为己方子 → 拒
- 行营安全岛：目标在行营 且 被敌方占 → 拒（行营中子不可被吃）
- 暗棋 cfg4：目标大本营内普通子（非雷非旗）→ 拒（大本营安全岛，暗棋特有）
- 暗棋 cfg4：目标为雷 → 仅工兵可攻；目标为旗 → 仅工兵且已挖满 3 雷
- 空大本营不可入（布局期仅军旗/地雷可入，对局期空大本营无落点）

路径判定（可判条款闭合，对齐 C move_legal:353-431）：
- 一步相邻（4 邻接：同行±1 列 或 同列±1 行）→ 允许
- **行营格约束**（闭合）：
  - 空行营：仅一步相邻可入（`is_camp(to) && !adjacent → 拒`，非铁路不可滑行进入）
  - 行营内子（若存在）：只能一步相邻走出（源侧自由，行营是安全岛非陷阱）
  - 行营内**敌子不可被吃**（`is_camp(to) && dst 非空 && dst.side!=me → 拒`）
  - 行营内**己方不可叠占**（目标己方子 → 拒，§3 目标约束）
  - 行营格**永不可作铁路滑行落点/中途通行**（`walkable` 视行营为不可通行；工兵 BFS 到达目标须 walkable，故滑行不落行营）
- 非相邻走铁路：
  - **工兵**：BFS 铁路网（可拐弯），中间格须可通行（空、非行营、非大本营）；**滑行终点须为空格**（吃子走相邻一步专属分支，工兵滑行不吃子）
  - **非工兵**：直线滑行（不拐弯），整行须为横铁路行(row0/5/6/11) 或 整列须为纵铁路列(col2)；纵线遇行营/大本营阻断；中间格须可通行（目标格可被占用=吃子，但目标为行营时已被上方行营条款拒）

## 4. 走子执行 + 结算（`try_move(from, to) -> 事件码`）

合法走子执行：源→目标交换 rank，按目标内容结算。

| 目标内容 | 结算 | 事件 |
|---|---|---|
| 空格 | 移动 | EV_MOVE |
| 敌方子（大吃小） | 吃子，源方留目标格 | EV_EAT |
| 敌方子（小碰大） | 被吃，目标方留源格 | EV_DEAD |
| 同级 | 互毁（双格清空） | EV_EAT（同级互杀用 EV_EAT，非 EV_BOMB） |
| 含炸弹（源或目标 rank=10） | 双格清空（同归） | EV_BOMB（**含炸弹撞旗：事件=EV_BOMB 非 EV_FLAG，恒判攻方胜，忽略 cfg3**） |
| 工兵挖雷（cfg2 开，目标 rank=11） | 雷消失工兵留位，mines_cleared[me]++ | EV_MINE |
| 工兵撞雷（cfg2 关） | 送死，工兵消失 | EV_DEAD |
| 扛军旗（目标 rank=12） | cfg3 开：攻方胜终局；cfg3 关：入位不终局继续 | EV_FLAG |

### 4.1 终局源优先级
吃旗/炸弹撞旗（即时终局）> 和棋 > 困毙（收口判定）。
- 吃旗成功（cfg3 开）：置 winner=攻方，stage=OVER
- 炸弹撞旗：**不受 cfg3 约束**，恒判攻方胜（炸弹分支在旗分支前命中）；**事件码=EV_BOMB（非 EV_FLAG），事件名级=Junqi.Bomb**（与扛旗 EV_FLAG 区分）
- 和棋（cfg0）：`moves_since_eat>=70` 或 `total_moves>=1000` → 判和
- **cfg3 关终局闭包**：扛旗入位（攻子落旗位、旗被移除不保留）后，**无二次扛旗胜**（旗位已被攻子占据）；该模式下终局仅余**和棋/困毙**两条路径（吃旗/炸旗即时终局均被 cfg3 关/炸弹恒判胜排除后的闭包）
- 困毙：**行动成功（走子/翻棋）且未即时终局时，先切 turn 至对手，再对当前行棋方（对手）做困毙判定**；困毙者负、对方胜。
  时序（对齐 C：行动 → 切 turn → stalemate_after 对 st->turn 判和棋/困毙）：
  ① 行动成功且非即时终局 ② turn=1-me ③ 先判和棋（cfg0 阈值）④ 未和棋则对**当前 turn 方**判困毙（无子可动/可翻 → 该方负）。
  **不可实现为"判刚行动方"。**

### 4.2 计步语义（逐分支真值表，对齐 C jq_try_move）
| 结算分支 | moves_since_eat | total_moves | 切 turn | stalemate_after |
|---|---|---|---|---|
| 空移 EV_MOVE | ++ | ++（尾部） | 是（PLAY 态） | 是 |
| 普通吃子 EV_EAT（大吃小） | =0 | ++ | 是 | 是 |
| 同级互毁 EV_EAT | =0 | ++ | 是 | 是 |
| 送死 EV_DEAD（src 弱被吃 sr>dr） | =0 | ++ | 是 | 是 |
| 炸弹同归 EV_BOMB（非撞旗） | =0 | ++（非终局尾部） | 是 | 是 |
| 炸弹撞旗（终局） | =0 | ++（分支内） | **否**（stage=OVER） | 否 |
| 扛旗 cfg3 开（终局） | =0 | ++（分支内） | **否**（stage=OVER） | 否 |
| 扛旗 cfg3 关（入位不终局） | =0 | ++ | 是 | 是 |
| 工兵挖雷 EV_MINE（cfg2 开） | =0 | ++（尾部） | 是 | 是 |
| 撞雷送死 EV_DEAD（非工兵 / cfg2 关） | **不变** | ++（尾部） | 是 | 是 |
| 翻棋 EV_FLIP | **不变** | **不变** | 是 | 是（翻棋收口） |

要点：
- **送死（src 弱被吃）`moves_since_eat=0`**（普通吃子比较块末尾统一清零，非 ++）；
  **撞雷送死 `moves_since_eat` 不变**（地雷未消失无子被吃，非"吃子活动"）。
- **翻棋不计步**（`moves_since_eat`/`total_moves` 均不动），和棋阈值只对走子累加。
- **终局步**（吃旗 cfg3 开 / 炸弹撞旗）：分支内置 `total_moves++` + `moves_since_eat=0`，**不切 turn、不走后续 stalemate_after**（stage=OVER 双守卫放行）。

### 4.3 回合流转
走子成功后 `turn = 1 - turn`（终局态不切）。翻棋成功后 `turn = 1 - turn`。

## 5. 翻棋（暗棋 FLIP 模式）

- 翻子对象：己方未翻暗子（`side==turn 且 !revealed`）或 0xFF 未定子（定色归当前 turn）
- 军旗不可翻；地雷可翻（`can_flip` 白名单只排军旗）
- 翻后 `revealed=1`，0xFF 子定色为当前 `turn` 阵营
- 翻棋后**切 turn**（`turn = 1 - turn`）+ 调终局收口（和棋/困毙判定），**不计步**（`moves_since_eat`/`total_moves` 不变，见 §4.2）；收口对象=切换后的当前行棋方（见 §4.1/S7）

### 5.1 暗棋 vs 明棋 关键差异
| 维度 | 明棋 LAY | 暗棋 FLIP |
|---|---|---|
| 初始 revealed | 全 1 | 全 0（0xFF 未定色） |
| 未翻暗子目标 | 不适用 | 可撞（翻出子可走/吃未翻暗子） |
| 雷/旗攻击 | 明棋任意子可扛旗 | cfg4 下仅工兵（雷无门槛，旗需挖满 3 雷） |
| 大本营安全岛 | 不适用 | 敌方不可吃大本营内普通子（雷/旗例外） |

### 5.3 开局初始化（30 字节布局 → 初始 jq_state，对齐 C layout.c:43-97/214-238）
输入 30 字节布局（蓝方 15 字节 × 镜像红方 15 字节），产出：
- **明棋 LAY**：全 60 格按布局镜像落子；蓝方 rank 原值（1-12），红方 rank+0xc（编码域 13-24）；非空格 `revealed=1`；`side` 蓝=0/红=1；`turn=BLUE(0), stage=PLAY, winner=NONE, mode=LAY`；`moves_since_eat=total_moves=0, mines_cleared=[0,0], pieces_left=[0,0]`
- **暗棋 FLIP**：同几何镜像；**双方 `side=SIDE_UNKNOWN(0xFF)`**（先手翻子定色，非开局预分配）；rank 用蓝方原值（暗棋红方不 +0xc，统一 raw 编码）；非空格 `revealed=0`；`turn=BLUE(0), mode=FLIP`
- 0xFF 未定色：暗棋开局全子 side=0xFF，首翻定色（翻子方归 side，见 §5.2/§9.3 翻棋候选）

### 5.2 困毙 vs 可翻 集合分层（原版设计）
- `can_flip`：翻雷**允许**（只排军旗）
- 困毙"可翻"扫描：**军旗 + 地雷都排**（翻出旗/雷都不能走，不计可行动）——对齐 C 正向 64 位 `jq_side_stalemated`（R-073 实证：`r==FLAG||r==MINE → continue`）
- 二者集合**故意不同**（翻=动作合法；困毙可行动=翻完须能走），非不一致缺陷
- ★ 审计 A3 修正（2026-11-20）：旧版规格误写"不排军旗"，与 C 64 位实证 + rprobe C4b 断言冲突，已更正为"排旗+雷"；Rust `rules.rs:side_stalemated` 实现本就对齐 C 64 位（排旗+雷），无需改代码，仅修文档笔误

## 6. 悔棋（undo）

- 悔棋粒度 = 整盘快照（走子/翻棋前整体拷贝 `jq_state`）
- 悔棋恢复：`*st = *snap` 全字段覆盖 + 清困毙缓存强制重算
- 悔棋**不重算**延迟到下次判定（`stalemate_after` 时刷新）
- 无走子级部分回滚（对齐原版 undo 栈设计）

---

## 7. 复盘（replay）

- 复盘 = 明棋范式：重建时强制全 `revealed=1`，从开局快照逐步重放走子
- 翻棋步重放：明棋范式重放前全翻开（revealed=1），翻棋步 `jq_flip` 因**目标已翻**而失败 → 回放重建**失败/中止**（`jq_replay_rewind_to` 返回 -1，快照回滚）。**暗棋翻棋序列不可忠实回放 = 设计边界**（C replay.c:72-110 实证：replay 仅对明棋走子序列有效）
- 复盘**不携带** BT 会话态（本规格已砍蓝牙）
- 复盘容量 N_REPLAY，满则静默截断

---

## 8. 存档（save）

- 全量快照：序列化整 `jq_state`（60 格 + turn + stage + winner + 计数 + mode + mines_cleared + stale 缓存）
- 读后校验（**分层语义**，对齐 C save.c:88-169）：
  - **头/枚举域校验失败 = 拒读（不覆写调用方状态）**：magic/sizeof 不符、`turn∈{0,1}`/`stage∈{0,1,2}`/`winner∈{-1,0,1,2}`/`mode∈{0,1}` 任一越域 → 直接返 0，`st` 不变
  - **cells 逐格 = 读入后就地净化**（非拒读）：`side∈{0,1,0xFF}`、`rank∈[0,24]`、`revealed∈{0,1}`，越域格强制归零（rank=0, side=0xFF, revealed=0, flags=0）
  - **计数负值 = 就地钳 0**：`pieces_left`/`mines_cleared` 负值钳 0（不拒读）
  - 即：枚举域"硬拒"，cells/计数"软净化"——二者策略不同（C 实证：域校验在 `*st=tmp_state` 前，cells/计数净化在覆写后）
- **失败/降级矩阵**（对齐 C save.c:126-168）：
  | 失败点 | 行为 | 调用方状态 |
  |---|---|---|
  | magic/sizeof 不符 | 拒读返 0 | 不变 |
  | 枚举域越界（turn/stage/winner/mode） | 拒读返 0 | 不变 |
  | cells 越域格 | 读入后就地归零 | 覆写（净化态） |
  | 计数负值 | 就地钳 0 | 覆写（钳制态） |
  | stale 缓存字段 | 原样保留（文件值） | 覆写（须调用方按需失效） |
  | undo 栈 / replay 序列 | 不持久化（仅棋盘态恢复） | 不重建（调用方负责） |
- 恢复后 undo 栈/replay 不重建（仅棋盘态恢复）

## 9. AI（人机对战，红方回合自动走子）

### 9.1 决策模型：单步贪心
红方回合时，遍历所有合法 `(from, to)`，对每个候选按 `ai_score` 取最高分者。
无合法着法 → 困局兜底（不推进，等待对方/判困毙）。

### 9.2 评分表（`ai_score(src_rank_raw, dst_rank_raw, dst_revealed) -> i32`，对齐 C rules.c ai_score:1243）
入参为**裸 rank**（红方已翻开存 rank+0xc，内部 rank_norm 还原；>24 脏值拒）。
```
+1000  吃子（rank_norm(src) < rank_norm(dst)；含炸弹撞旗 10<12）
 +900  同级互毁（rank_norm(src) == rank_norm(dst)，含炸弹撞炸弹）
 +800  炸弹同归（src 或 dst 为炸弹 10；炸弹撞普通子 1-9 / 炸弹撞雷 11）
 +700  工兵挖雷（src=9 工兵, dst=11 雷）
    2  空移（dst 空）
    2  暗棋未翻暗子目标（dst 非空 且 dst_revealed=0 → 不透视，恒 2）
    1  送死（src 弱碰 dst 强 / 普通子撞雷 11）
   -1  源为军旗/地雷（rank_norm=12/11 不可走）
   -2  脏输入（rank<0 / src>24 / 空源）
```
**暗棋不透视**：`dst_rank!=0 且 dst_revealed=0` → 恒给 2（不透视敌子真 rank）。
**雷目标特判**（dst_revealed=1 已翻雷）：工兵 700 / 炸弹撞雷 800 / 普通子撞雷 1。

### 9.3 AI 选着策略（对齐 C jni_bridge.c ai_pick:309）
- **候选生成**：遍历 AI 方（turn=RED）已翻子（side==me 且 revealed），跳过旗/雷源；
  对每个合法目标（`can_move`）算 ai_score；**暗棋下未翻非空目标不入候选**（与 move_legal 拦截一致）。
- **难度分流**：level==1（新手区）取 `sc>=2` 中**最小分**（被动游走）；level>=2 取**最高分**（贪心）。
- **无走子 → 翻棋回退**：遍历未翻子，接受 `side==me || side==0xFF`（0xFF 定色归 me），
  跳过军旗，过 `can_flip` 者执行翻棋（from==to, is_flip=1）。
- **兜底**：无候选返回 -1（困局，等待对方/判困毙）。
- **入参假设**：src_rank 为 AI 方棋子裸 rank（红方 +0xc 编码），dst_revealed 为目标揭示位。

### 9.4 AI 介入门控
- 仅 `vs_ai==1`（人机模式）且 `turn==RED` 且 `stage==PLAY` 时介入（§9.3 策略在此门控内执行）
- 两人热座 / 非 PLAY 阶段 AI 不介入
- AI 走子与玩家走子同走 `try_move` 通道（同一套规则引擎）

## 10. UI 状态机（人机对战相关屏态）

| 屏态 | 迁移 | 关键不变量 |

### 10.1 面板外 = 取消语义（通病根治）
所有设置类弹窗（游戏设置/音效/亮度/图像/规则）**点面板外** = 取消，须回滚未保存变更，
与"取消"按钮对称。历史缺陷：部分弹窗面板外仅切屏不回滚。

### 10.2 输入事件→屏态迁移条件表（可判，对齐 C jni_bridge OnTouch/OnEvent）
| 屏态 | 输入事件 | 命中判定 | 迁移 + 副作用 | 未命中/面板外 |
|---|---|---|---|---|

## 11. 事件契约（音效/统计）

**7 种事件码（0-6），对应 6 个不同事件名字符串**（挖雷与空移同名 `Junqi.Move`）：

| 码 | 枚举 | 事件名级（音效匹配） | 说明 |
|---|---|---|---|
| 0 | EV_MOVE | Junqi.Move | 空移 |
| 1 | EV_EAT | Junqi.Eat | 普通吃子/同级互毁 |
| 2 | EV_BOMB | Junqi.Bomb | 炸弹同归（含炸弹撞旗） |
| 3 | EV_FLAG | Junqi.Flag | 扛旗（cfg3 开终局） |
| 4 | EV_DEAD | Junqi.Dead | 被吃/送死 |
| 5 | EV_MINE | **Junqi.Move**（与码 0 同名） | 工兵挖雷 |
| 6 | EV_FLIP | Junqi.Flip | 翻棋 |

- 事件**码**分流统计（7 码独立计数，EV_MINE 与 EV_MOVE 虽同名但计数按码 0/5 分桶）
- 事件**名**分流音效（按名匹配 14 WAV；Junqi.Move 同时驱动码 0/码 5 两种音效时机）
- 分发成功 ≠ 业务实现（部分事件为分发桩，无状态变更）

## 12. 诚实边界（禁自欺）
- 行为级对齐，非汇编级等价
- 桌面测试 PASS ≠ 真机出屏达成（设备 PENDING）
- 暗棋翻棋复盘不可忠实回放（明棋范式边界）
- 存档恢复 ≠ 可续联机（已砍蓝牙，纯本地）
