## 一、0xb6808 完整控制流 (实证)

### 函数签名
```
r0 = 状态对象指针 (基址)
r1 = 目标格索引 (to)
r2 = 结果/上下文
r4 = r1 (目标格)
```

### 控制流
```
1. 边界检查:
   b6810:  cmp r1, #7          ← to <= 7?
   b6812:  bhi → 越界处理 (b681e)

2. 位运算:
   b6814:  movs r2, #1
   b6816:  lsls r2, r1         ← r2 = 1 << r1
   b6818:  movs r3, #134       ← 0x86 = 134
   b681a:  tst r2, r3          ← 测试 bit (1<<r1) & 134
   b681c:  bne → b684a         ← 命中特殊格 (炸弹/地雷位?)

3. 对象字段检查:
   b681e:  movs r3, #196       ← 0xc4 = 196
   b6820:  ldr r0, [r5, r3]    ← 读对象 +196
   b6822:  cmp r0, #0          ← 非 0?

4. ★ rank 判定 (cmp r4, #N):
   b6826:  cmp r4, #2          ← to == 2?
   b682a:  cmp r4, #7          ← to == 7?
   b682e:  cmp r4, #1          ← to == 1?

5. 虚函数分发:
   b6842:  ldr r3, [r3, #44]   ← vtable[44]
   b6846:  blx r3             ← 调用

6. 对象字段写入:
   b6858:  str r0, [r5, #108]  ← 写 +108
   b6864:  str r0, [r5, #112]  ← 写 +112
```

## 二、★ rank 编码对照 (32 位 vs 64 位)

### 32 位 0xb6808 实证
- `cmp r4, #2/#7/#1` = 目标格索引判定 (to == 1/2/7)
- `cmp r1, #7` = 边界检查 (to <= 7)
- **非棋子 rank 比较, 而是格索引判定**

### 64 位 src_rs rank 编码 (junqi.h)
```c
#define RANK_EMPTY   0
#define RANK_BOMB    10   /* 0x0a */
#define RANK_MINE    11   /* 0x0b */
#define RANK_FLAG    12   /* 0x0c */
#define RANK_TOP     12
#define RANK_WORKER  9    /* 工兵 */
#define RANK_COUNT   13   /* 0-12 */

// 棋子等级 1-9 (普通):
// 1=兵 2=卒 3=列 4=营 5=连 6=团 7=旅 8=师 9=军
```

### ★ 对照结论
| 维度 | 32 位 0xb6808 | 64 位 src_rs | 一致性 |
|------|--------------|--------------|--------|
| 边界检查 | `cmp r1, #7` (to <= 7) | jq_can_move 界检查 (0-59) | **不一致** (7 vs 59) |
| rank 判定 | `cmp r4, #2/#7/#1` (格索引) | rank_of (棋子等级 1-12) | **不一致** (格索引 vs 棋子 rank) |
| 对象布局 | +196/+192/+108/+112 | jq_state 结构体 | 需对照 |

### 风险等级
- **P0 风险**: 32 位 0xb6808 的 `cmp r1, #7` 边界 = 小棋盘 (8 格?), 64 位 = 12×5 大棋盘 (60 格)
  - 可能 0xb6808 非走子验证, 而是**特殊格处理** (如炸弹/地雷位判定)
  - 需 Frida 运行时确认 0xb6808 调用上下文
- **P1 风险**: rank 编码 (1-12 vs 1-9+特殊) 需对照

## 五、教训固化

### 5.1 格索引 vs 棋子 rank (本轮关键教训)
```
ARM cmp rX, #N 的 N 值含义需上下文:
  - 若 rX = 格索引 (to) → N = 格号 (1/2/7 = 特殊格)
  - 若 rX = 棋子 rank → N = 等级 (1-9 普通, 10-12 特殊)

误判风险:
  "cmp r4, #2" 可能是格索引 2, 非棋子 rank 2 (卒)
  需追踪 r4 来源 (参数/局部/全局) 才能定含义

本轮教训:
  0xb6808 的 cmp r4, #2/#7/#1 初判 "rank 判定" 系误读
  实为格索引判定 (to == 1/2/7)
```

### 5.2 边界值 7 的解读
```
32 位 cmp r1, #7 (to <= 7):
  - 若大棋盘 0-59 → 边界 7 不合理
  - 若特殊格区 (0-7) → 合理 (如 8 个特殊位: 炸弹×2/地雷×2/军旗×2/?)

64 位 jq_can_move 界检查:
  - 0-59 (12×5 大棋盘)
  - 或 0-7 (特殊格区, 若 32 位口径)

对照: 需确认 32 位 0xb6808 的边界 7 是否 = 特殊格区
```
