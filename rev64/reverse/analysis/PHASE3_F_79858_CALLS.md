## 二、原版 0x557d4 验证 (★ 纠正 AUD_ALIGN_R16 推测)

### 实证 (原版 lib/armeabi/libjunqi.so)
```
557d4:  2384       movs  r3, #132    ← 常量 132
557d6:  58c0       ldr   r0, [r0, r3] ← 读对象 +132 字段
557d8:  4770       bx    lr          ← 返回
```

### 结论
- **0x557d4 是 getter thunk** (读对象偏移 132 字段), **非 AI 评分逻辑**
- AUD_ALIGN_R16 原稿 "评分逻辑真实地址 = 0x557d4" **系推测, 已被实证纠正**
- 0x55d40 thunk 区 (55d30-55d7c) 全是 12-16 字节的短 thunk:
  ```
  55d30: push {r4,lr}; ldr r0,[r1,r0]; bl 55824; pop {r4,pc}   ← 事件业务 thunk
  55d40: push {r4,lr}; ldr r0,[r1,r0]; bl 557d4; pop {r4,pc}   ← getter thunk
  ```
- 评分逻辑真实地址**仍未定位** (★ 0x55d40 区 75 thunk bl 目标已收表, 无评分特征, 见 ORIG_THUNK_55d40_ANALYSIS.md)
