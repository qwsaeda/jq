## 一、F_9e2b4 (OnUpdate 主循环核心)

### 函数信息
- 地址: 0x511d54
- 大小: ~0x580 (1408 字节)
- 栈帧: 220 字节局部空间
- 参数: r0-r3 (4 个)

### 调用目标
| 目标 | 符号 | 用途 |
|------|------|------|
| 0x328a88 | jqt_mem_addr | .bss 全局变量访问 (密集) |
| 0x8a6150 | __aeabi_memclr | memset 封装 |
| 0x4cb1f0 | F_9e0f0 | 子逻辑 (条件分支) |
| 0x4f7f74 | F_9e204 | 辅助函数 |

### 控制流结构
```
入口 → 参数保存 → 局部初始化 (movw r0, #0)
     → [循环体]
         1. jqt_mem_addr 读 .bss 状态
         2. 条件判断 (cmp r0, #0 / cmp r0, r1)
         3. 分支:
            - beq → 跳过 (空状态)
            - bne → 执行 F_9e0f0 (核心逻辑)
         4. F_9e204 (辅助处理)
         5. 循环条件更新
     → 出口
```

### 推测功能
- **帧更新入口**: 读取 .bss 游戏状态 → 判断是否需要处理 → 调用子函数
- **条件分支密集**: 多个 `cmp r0, #0` = 检查指针/状态是否为空
- **调用 F_9e0f0**: 可能是渲染更新 / AI 决策 / 事件处理

## 二、F_2af44 (OnTimer AI 决策)

### 函数信息
- 地址: 0x7f5cac
- 大小: ~0x500 (1280 字节)
- 栈帧: 188 字节局部空间
- 参数: r0-r3

### 调用目标
| 目标 | 符号 | 用途 |
|------|------|------|
| 0x328a88 | jqt_mem_addr | .bss 访问 (30+ 次) |
| 0x328be8 | jqt_mem_rebuild | 内存重建 |
| 0x7f6590 | F_2afa4 | AI 核心逻辑 |
| 0x8a6150 | __aeabi_memclr | memset |
| 0x468d40 | _Znwj | C++ new (malloc) |

### 控制流结构
```
入口 → 参数保存 → 局部初始化
     → [AI 决策循环]
         1. jqt_mem_addr 读 .bss (棋盘状态 / 回合 / 玩家)
         2. jqt_mem_rebuild (内存重建, 可能刷新缓存)
         3. F_2afa4 (AI 走子逻辑)
         4. 条件分支:
            - 可走子 → 执行走子
            - 不可走子 → 等待 / 困毙判断

     → 出口
```

### 推测功能
- **AI 回合处理**: 读取当前玩家/回合 → 判断是否 AI 走 → 调用 F_2afa4 决策
- **密集 .bss 访问**: 30+ 次 jqt_mem_addr = 读写大量全局状态
- **调用 F_2afa4**: 可能是走子算法 / 吃子判断 / 翻棋逻辑

## 五、逆向结论

### 5.1 主循环模式 (F_9e2b4)
```
OnUpdate 每帧调用:
  1. 读取 .bss 游戏状态
  2. 判断是否有待处理事件
  3. 调用 F_9e0f0 (渲染 / AI / 事件)
  4. 更新 .bss (帧计数 / 时间戳)
```

### 5.2 AI 决策模式 (F_2af44 → F_2afa4)
```
OnTimer 触发 (玩家走子后 / 定时器):
  1. 读取 .bss 回合 / 玩家
  2. 判断是否 AI 回合
  3. 调用 F_2afa4 (走子算法)
  4. 验证 (F_a4544)
  5. 写回 .bss (更新棋盘 / 回合)
```

### 5.3 与 64 位重写的关联
- **行为对齐**: 64 位 src_rs 已有 `ai_pick` / `jq_can_move` / `jq_can_flip`
- **差异点**: 32 位 AI 决策细节 (候选排序 / 评估函数) 需进一步逆向
- **产出**: 本逆向结果 → 验证 64 位 AI 行为是否一致
