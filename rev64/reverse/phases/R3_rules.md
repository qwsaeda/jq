# 阶段 R3 · 核心玩法规则（标准中国军棋）

## 目标
- 实现标准中国军棋（陆战棋）完整规则：走子/吃子/炸弹/军旗/地雷/翻棋/胜负。
- 提供 `jq_can_move`（判定）/`jq_try_move`（执行）分层，供 JNI/渲染/联机复用。

## 规则规范（标准军棋）

### 棋子等级（降序）

| 40 | 司令 | 1 |

### 走子规则
- 一格相邻移动（上下左右，非斜）。
- 铁路直线滑行（同行/同列，中间全空/非敌方行营/非大本营）。
- 工兵沿铁路可拐弯（BFS 任意路径）。
- 大本营内子不可动；军旗/地雷不可动；行营内子可出。
- 目标不能是己方子；不能进入敌方行营。

### 吃子规则
- 大压小：大者胜，占位；小者被吃。
- 同级/炸弹碰撞：同归于尽（双方子消失）。
- 工兵挖雷；其他子撞雷=被炸。
- 炸弹炸任何子（同归于尽）。
- 吃军旗=胜。

### 回合
- 蓝红交替，`st->turn` 记录当前方。
- `jq_try_move` 成功后翻转 turn。

## 接口规范
```c
bool jq_can_move(const jq_state *st, int from, int to);   /* 判定（不改变状态） */
jq_move_result jq_try_move(jq_state *st, int from, int to); /* 执行（含吃子/胜负） */
bool jq_can_flip(const jq_state *st, int idx);            /* 暗棋可翻 */
bool jq_flip(jq_state *st, int idx);
bool jq_is_game_over(const jq_state *st);
```
- `jq_move_result`：JQ_MOVE_OK / JQ_MOVE_BLOCKED / JQ_MOVE_WIN。

## 经验（→ LESSONS）
- L23：走子规则自检清单。
- **低撞高是允许的走法**：`jq_can_move` 返回 1（可走），`jq_try_move` 才判负/送死。
- 地雷 rank 用 **JQ_RANK_MINE=31**（非零），避免与 JQ_EMPTY=0 冲突（否则地雷被当空格跳过）。

## 复用指引
- JNI OnTouch 已接入：坐标→格→`jq_can_move/try_move`（`handle_tap` 状态机）。
- 单机对弈：蓝方玩家触屏，红方 `jq_ai_move` 在 OnUpdate 自动回应。
- 悔棋/重开：`jq_undo`（OnEvent "undo"）、重载布局（OnEvent "restart"）。
- 联机协议（R5 未完成）需把 `jq_move_result` 映射为 `Junqi.Move/Eat/Dead` 事件。

## 已验证
- 走子：空位相邻=可走；己方子/敌方行营/军旗/地雷=不可；大本营内子不可动。
- 吃子：大压小（38吃36 红剩24）；同级同归于尽；低撞高允许（送死）。
- 胜负：吃军旗 → winner 置位、stage=OVER；**困毙**（对方无子可动）→ 胜（L33）。
- 大本营：军旗固定大本营，其他子禁入（L34）。
- 布局：default.lay 30字节 → 每方25子（分布精确匹配标准军棋），蓝军旗行0/红军旗行11。
- 触屏：60 格坐标映射全正确；选中→走子状态机正常（L24）。
- AI：蓝红对弈 29 步不卡死（L25）。
- 悔棋：源格/目标格/剩余子数/当前方全部恢复（L29）。
