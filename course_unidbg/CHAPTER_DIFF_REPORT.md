## 7 处实质偏差（按等级排序，全部已修完 2026-11-02）

### ✅ 高：第 19 章标题与正文口径不一致（已修）
- **原书**：第 19 章标题"unidbg 实战：魔改 Base64 还原"（书内样本是魔改 Base64）
- **课程现状**：正文 19.1/19.2 已纠正"军棋实际是 SPAK 的 XOR(key[j%32]) + zlib"，但**章标题仍叫"魔改 Base64 还原"**
- **修法**：章标题改成"SPAK 资源解密还原（原书：魔改 Base64，军棋实际是 XOR+zlib）"
- **状态**：✅ 已改 ch19 章头说明段，正文保留"魔改 Base64"作为原书方法论对照

### ✅ 中：第 13 章 13.2"JNI 指令执行"讲串（已修）
- **原书**：13.2 专讲 `RegisterNatives` 注册后，JNI 函数指令如何分发（native 函数表调用、参数 marshal）
- **课程现状**：13.2 标题"JNI 指令执行（实际通话：14 个入口被调）"，把"指令执行"和"14 入口被调"混为一谈，缺"参数 marshal（JNIEnv 怎么把 Java 参数传给 native）"
- **修法**：13.2 补"参数 marshal"小节（军棋 `OnCreate(env, obj)` 的 env/obj 怎么从 DalvikVM 的 DvmObject 转成 native 指针）
- **状态**：✅ 已加 13.1.1 参数 marshal（军棋 14 入口 marshal 差异表 + `&~1` 对齐）

### ✅ 中：第 14 章漏"虚拟模块"（已修）
- **原书**：14.2.4 专讲 virtual module（虚拟模块，把"不是真 so 的内存块"挂成 module，军棋挂 7 依赖用）
- **课程现状**：14.2 只讲"4 组件 + 6 步 loader"，没提 virtual module 概念
- **修法**：14.2 补"虚拟模块"小节（军棋 7 依赖库 = 7 个 virtual module 挂在 SvcMemory）
- **状态**：✅ 已加 14.2.1 虚拟模块（军棋 7 依赖 + GL 桩 + JNI 函数表 3 类虚拟模块）

### ✅ 中：第 22 章 22.2 细度丢（已修）
- **原书**：22.3 拆 4 个独立小节（22.3.1 参数获取 / 22.3.2 代码初始化 / 22.3.3 目标函数调用 / 22.3.4 补环境说明 / 22.3.5 补环境实战）
- **课程现状**：22.2 把 4 个小节并成"补环境实战 3 步（代码）"，丢了"参数获取"和"补环境说明"的独立性
- **修法**：22.2 拆回原书 5 小节结构（参数获取 / 代码初始化 / 目标函数 / 补环境说明 / 补环境实战）
- **状态**：✅ 已拆回 22.2.1 参数获取 / 22.2.2 代码初始化 / 22.2.3 目标函数 / 22.2.4 补环境说明（四层）/ 22.2.5 补环境实战（§124 三项阻塞）

### ✅ 低：第 17 章"Patch 自吐"没单独展开（已融入）
- **原书**：17.2.3 专讲"用 Patch 自吐"（改写指令让 so 把值写进内存）
- **课程现状**：17.2"自吐 3 路径"提了 Patch 但并到 3.5（军棋 Patch 极少用），没单独讲"Patch 怎么自吐"

### ✅ 低：第 24 章漏"ActivityThread"（已修）

### ✅ 低：第 25 章"无障碍服务"过简（已修）
