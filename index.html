边界说清楚

64 位原生是简化版

arm64 so 是 NDK 简化重写（棋盘、走子、简单 AI），不是 32 位 1.43MB 原生的汇编级逆向。交付物里不把它说成完整版。

redroid 只提数据

容器无 GPU，进不了主界面；64 位 native bridge 不完整。它只用于提取 .rodata 明文与验证初始化链，不用于验证可玩。

阶段 0 的 32 位 so 依赖广告 jar

32 位原生的 baidu 引用是硬依赖，去广告只能删权限留 jar。阶段 3 的全量去广告只在 arm64 路线上成立。
